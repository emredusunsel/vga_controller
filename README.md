# vga_controller
SystemVerilog VGA controller with 640x480 video timing, test patterns, and simulation-based frame capture for the DE10-Lite FPGA.

- task files explain the functionality.

- ...bars_tb, ...grad_tb, ...rect_tb for image generation.

- ...signal_tb for timing and signaling tests

- Module hierachy: 
- - vga_core(vga_pattern, vga_timing)
